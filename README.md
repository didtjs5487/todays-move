# 오늘의 무브

목표와 가진 장비에 맞춰 **오늘 할 운동 한 세트**를 뽑아 주고, 인터벌 타이머로 따라 하며
기록이 쌓이는 개인 운동 앱. 설치형 웹앱(PWA)이라 홈 화면에서 앱처럼 열리고,
한 번 연 뒤에는 인터넷이 끊겨도 그대로 돌아갑니다.

## 쓰는 법

- **목표** 여섯 가지(체지방 감량·근력·근지구력·심폐지구력·폭발력·회복/유연) 중 하나와
  **시간**(8~30분)을 고르면 그에 맞는 구성이 나옵니다.
- 마음에 안 드는 동작은 그 줄의 `바꾸기`로 하나만 교체, 전체가 싫으면 `다시 뽑기`.
- `시작`을 누르면 준비 12초 뒤 인터벌 타이머가 돌아갑니다(남은 3초 알림음·다음 동작 음성 안내).
- **설정**에서 가진 것(밴드·덤벨·의자), 해볼 갈래(플라이오메트릭·애니멀 플로우),
  조용히 하기(뛰는 동작 제외), 강도를 정합니다.
- 최근 3회에 나온 동작은 뒤로 밀려, 며칠 이어서 해도 같은 구성이 겹치지 않습니다.
- **동작 이름을 누르면** 그림(시작 자세 ↔ 끝 자세)과 순서, 흔한 실수, 바꿔 할 수 있는
  동작, 영상 검색이 나옵니다. 타이머에서도 쉬는 동안 다음 동작의 그림과 첫 순서를 보여 줍니다.

## 홈 화면에 설치

- **안드로이드/크롬** — 주소를 연 뒤 `설정` 탭의 `설치` 단추, 또는 브라우저 메뉴 → 앱 설치
- **아이폰/사파리** — 공유 단추 → 홈 화면에 추가
- **PC/크롬** — 주소창 오른쪽 설치 아이콘

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체(화면·동작 사전 83가지·타이머·기록) |
| `manifest.webmanifest` | 앱 이름·아이콘·시작 주소 — 설치에 쓰입니다 |
| `sw.js` | 오프라인에서도 열리도록 파일을 담아 두는 서비스 워커 |
| `icon*.png`, `icon.svg` | 홈 화면 아이콘(활동 링 + 심박 파형) |

기록과 설정은 **이 브라우저에만** 저장됩니다(localStorage). 서버로 나가지 않습니다.

`sw.js`의 `V` 값을 바꾸면 사용자 기기의 옛 캐시가 정리되고 새 화면이 받아집니다.
